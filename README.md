Photo Editing Website

Ctrl+C / Cmd+C - Copy selected photo
Ctrl+V / Cmd+V - Paste copied photo
Delete / Backspace - Delete selected photo
Ctrl+D / Cmd+D - Duplicate selected photo
Arrow Keys - Move selected photo (hold Shift for faster movement)
R - Rotate selected photo
Escape - Deselect photo
Enter - Add Photo
